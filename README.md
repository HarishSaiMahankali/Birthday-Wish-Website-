## 📸 How to Personalize
This project currently uses placeholders. To add your own photos and videos:
1.  Go to the `assets/` folder.
2.  Replace the `placeholder.svg` or `placeholder_song.m4a` files with your actual media.
3.  Or, update the paths in `script.js` and HTML files to match your new filenames.

## 🚀 How to Deploy (Enable the Link)
To make the "Live Demo" link work:
1.  Go to **Settings** in this GitHub repository.
2.  Scroll down to the **Pages** section (on the left sidebar).
3.  Under **Source**, select `Deploy from a branch`.
4.  Under **Branch**, select `main` and `/ (root)`.
5.  Click **Save**.
6.  Wait a minute, and the link above will start working!
